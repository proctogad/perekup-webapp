# DiscordCatalog

Каталогизатор каналов Discord: выгружает все категории и каналы сервера
в JSON (для кода) и Markdown (для чтения), а также создаёт роли — по одной
на каждый канал плюс особые (источник входа, персонал, заслуги).

## Файлы

| Файл | Что это |
| --- | --- |
| `catalog_channels.py` | каталог каналов: JSON + Markdown (Python 3.10+, без зависимостей) |
| `create_roles.py` | создание ролей по плану (предпросмотр по умолчанию, `--apply` — создать, `--order` — разложить по порядку) |
| `setup_staff.py` | права персоналу и доступ к «Администрации» (шаги 5–6 из `SETUP.md`) |
| `finish_setup.py` | закрыть Community, создать `#роли`, включить защиту и описания каналов (шаг 7) |
| `create_invites.py` | 4 бессрочные инвайт-ссылки Telegram / EXE / сайт → `PerekupDisBot/invites.json` (шаг 8) |
| `post_update.py` | вебхук `Perekup Updates`, тест и анонсы релизов в `#обновления` (шаг 10) |
| `discord_api.py` | общий клиент Discord API (токен, `.env`, запросы, поиск сервера) |
| `roles.plan.json` | план ролей: одна роль на канал + источник входа + персонал + заслуги |
| `roles.md` | дизайн ролей по-человечески: что, зачем и что выдать вручную |
| `rules-text.md` | готовый текст правил для `#правила` |
| `SETUP.md` | пошаговая настройка: от создания бота до вебхука (для нетехнического запуска) |
| `.env.example` | шаблон токена, ID сервера и вебхука |
| `examples/github-release-webhook.yml` | workflow: анонс GitHub Release в Discord |
| `channels.from-screenshot.json` / `.md` | каталог, переписанный по скриншоту (ID не извлекаются из картинки) |
| `channels.json` / `channels.md` | результат реального запуска (создаётся скриптом) |

Сам Discord-бот живёт в соседней папке **`PerekupDisBot`** — там `bot.py`,
`config.json`, `Dockerfile` и инструкция по деплою.

## Быстрый старт

Нужен бот на сервере и его токен.

1. Создать приложение и бота: <https://discord.com/developers/applications>
2. В разделе **Bot** скопировать токен.
3. Добавить бота на сервер (OAuth2 → URL Generator → scopes `bot`,
   permissions `View Channels`, `Manage Channels`, `Manage Roles`
   (`Manage Roles` — для создания ролей)).
4. Выполнить:

```powershell
$env:DISCORD_BOT_TOKEN = "твой-токен"
python catalog_channels.py --guild-name "Перекуп Калькулятор" --counts --stats
```

5. Создать роли для каждого канала (см. `roles.md`, пошагово — `SETUP.md`):

```powershell
python create_roles.py --guild-name "Перекуп Калькулятор"                  # предпросмотр
python create_roles.py --guild-name "Перекуп Калькулятор" --apply          # создать
python create_roles.py --guild-name "Перекуп Калькулятор" --apply --order  # + разложить по порядку
python setup_staff.py --guild-name "Перекуп Калькулятор" --apply           # права персоналу и «Админка»
python finish_setup.py --guild-name "Перекуп Калькулятор" --apply          # Community, #роли, описания
python create_invites.py --guild-name "Перекуп Калькулятор" --apply        # инвайты Telegram/EXE/сайт
python post_update.py --guild-name "Перекуп Калькулятор" --create-webhook --apply  # вебхук обновлений
```

Дальше запусти Discord-бота из `PerekupDisBot` (см. `PerekupDisBot/README.md`)
и опубликуй панели командами `/panel` и `/verify-panel`.

Либо ID сервера (включить Developer Mode в Discord → ПКМ по серверу → «Копировать ID»):

```powershell
python catalog_channels.py --guild-id 123456789012345678 --threads
```

## Ключи

| Ключ | Назначение |
| --- | --- |
| `--guild-id` | ID сервера |
| `--guild-name` | поиск сервера по подстроке имени среди серверов бота |
| `--token` | токен бота (иначе берётся `DISCORD_BOT_TOKEN`) |
| `--out-dir` | каталог для файлов (по умолчанию текущий) |
| `--prefix` | префикс имён файлов (по умолчанию `channels`) |
| `--threads` | включить треды |
| `--counts` | запросить счётчики сообщений и участников (медленнее) |
| `--stats` | сводка по типам и категориям в консоль |

## Роли по каналам

План ролей живёт в `roles.plan.json` (одна роль на каждый канал, плюс
источник входа `📱 Из Telegram` / `🖥️ Из EXE` / `🌐 С сайта`, персонал и
заслуги), описание — в `roles.md`. Скрипт идемпотентен: роли ищутся по
имени, повторный запуск ничего не дублирует. Без `--apply` — только
предпросмотр. Порядок групп в плане = порядок иерархии сверху вниз;
`--apply --order` раскладывает все роли автоматически и сам поднимает
роль бота, если она оказалась внизу списка.

| Ключ | Назначение |
| --- | --- |
| `--guild-id` | ID сервера |
| `--guild-name` | имя сервера (по умолчанию — из плана) |
| `--token` | токен бота (иначе `DISCORD_BOT_TOKEN`) |
| `--plan-file` | другой файл плана ролей |
| `--list` | показать план без обращения к API |
| `--apply` | реально создать роли |
| `--update` | подтянуть цвет/пинг/hoist у уже существующих ролей |
| `--order` | разложить роли по порядку иерархии (порядок групп в плане = сверху вниз) |

Требования: право **Manage Roles**, и высшая роль бота должна быть выше
создаваемых (с `--order` скрипт поднимает роль бота сам, а если Discord не
разрешит — попросит перетащить её вверх в настройках сервера). Все роли
создаются с нулевыми правами — администратора владельцу и права модерации
команде выдайте вручную после проверки (см. `roles.md`).

## Частые ошибки

| Сообщение | Причина |
| --- | --- |
| `401 Unauthorized` | неверный токен или это не Bot-токен, а User-токен |
| `403 Forbidden` | бот не видит канал: нет права `View Channel` / `Manage Channels` |
| `403 Forbidden` при создании роли | у бота нет права `Manage Roles` или его высшая роль ниже создаваемых |
| `404 Not Found` | бот не добавлен на сервер или неверный ID |
| `сервер не найден` | бот не состоит ни в одном общем сервере либо имя не совпало |

## Лимиты

Один запрос на сервер — скрипт укладывается в лимит. При 429 он сам ждёт
`retry_after` и повторяет запрос, при 5xx — делает до 5 попыток с задержкой.
