# Пошаговая настройка — от нуля до готового сервера

Инструкция для сервера «Перекуп Калькулятор». В конце: 29 ролей, права
персонала, закрытый Community, канал `#роли`, инвайт-ссылки, Discord-бот
с кнопками и вебхук обновлений. Займёт ~20 минут.

Что понадобится: права администратора на сервере и Python 3.10+ на
компьютере (проверка: `python --version`).

---

## Шаг 1. Создать бота и получить токен

1. Открой <https://discord.com/developers/applications> → **New Application**.
2. Имя — любое, например `Перекуп Калькулятор Bot`. Создать.
3. Слева вкладка **Bot**:
   - при желании загрузи аватар бота (тут же, в **Bot**);
   - нажми **Reset Token** → **Copy** — это и есть токен. Он показывается
     один раз, сохрани его в надёжное место (менеджер паролей).
   - Интенты включать **не нужно** — скрипт работает без них.

> Токен — это пароль бота. Не выкладывай его в чаты, скриншоты и GitHub.
> Если засветился — Reset Token и старый сразу станет недействителен.

## Шаг 2. Пригласить бота на сервер

Портал разработчика русский не поддерживает — ниже указано, что искать по-русски.

1. На странице приложения слева — раздел **OAuth2**, внутри вкладка
   **URL Generator** («генератор ссылок»).
2. Блок **Scopes** («области доступа») — поставь галочку `bot`.
3. Ниже появится блок **Bot Permissions** («права бота») — отметь галочки:
   - `View Channels` — «Просмотр каналов»,
   - `Manage Roles` — «Управление ролями» (обязательно: без этого роли не создать),
   - `Manage Channels` — «Управление каналами» (пригодится для доступа к категориям).
4. Внизу в поле **Generated URL** («получившаяся ссылка») нажми
   **Copy** («копировать») и вставь ссылку в адресную строку браузера.
   Либо собери ссылку сам: в разделе **General Information** («общая
   информация») скопируй **Application ID** (он же Client ID — длинное
   число) и подставь вместо `ТВОЙ_CLIENT_ID`:

   ```
   https://discord.com/oauth2/authorize?client_id=ТВОЙ_CLIENT_ID&scope=bot&permissions=268436496
   ```

5. В открывшемся окне Discord: в поле «Добавить на сервер» выбери
   **Перекуп Калькулятор** → нажми **«Авторизовать»**
   (по-английски **Authorize**) → пройди капчу.
6. Готово: бот появится в списке участников, а в «Настройках сервера →
   Роли» появится его автоматическая роль с именем приложения.

| Что искать в портале (англ.) | По-русски |
| --- | --- |
| OAuth2 → URL Generator | «генератор ссылок» |
| Scopes | «области доступа» |
| Bot Permissions | «права бота» |
| Generated URL | «получившаяся ссылка» |
| Copy | «копировать» |
| General Information | «общая информация» |
| Application ID / Client ID | идентификатор приложения (одно и то же) |

## Шаг 3. Роль бота — обычно ничего делать не нужно

Новые роли появляются внизу списка, а бот может управлять только тем, что
лежит ниже его собственной роли. Поэтому при расстановке порядка (шаг 4,
команда с `--order`) скрипт сам поднимет роль бота на самый верх.

Если он напишет «перетащите роль бота» — сделай это мышкой:
**Настройки сервера → Роли** → перетащи роль с именем приложения
(у нас — `Perekup`) в самый верх списка, и запусти команду ещё раз.

## Шаг 4. Запустить скрипты

Открой PowerShell и выполни по очереди:

```powershell
cd H:\Repozit\DiscordCatalog

# 1. Посмотреть план ролей (токен не нужен)
python create_roles.py --list

# 2. Сохранить токен в переменную окружения (только для этого окна)
$env:DISCORD_BOT_TOKEN = "вставь-сюда-токен"

# 3. Предпросмотр: какие роли создадутся, какие уже есть
python create_roles.py --guild-name "Перекуп Калькулятор"

# 4. Создать роли
python create_roles.py --guild-name "Перекуп Калькулятор" --apply

# 5. Разложить роли по порядку (Владелец — вверху, Новичок — внизу)
python create_roles.py --guild-name "Перекуп Калькулятор" --apply --order
```

Ожидаемый итог: `итог: создано 29 · обновлено 0 · уже было 0`, а после
шага 5 — список ролей сверху вниз, как в `roles.md`.

- Повторный запуск **безопасен**: роли ищутся по имени и не дублируются.
- Имя сервера можно писать любым куском и в любой раскладке — «Перекуп»,
  «GTA5RP», «ГТА5РП» — скрипт найдёт сам. Но если сомневаешься, надёжнее
  всего `--guild-id`: включи режим разработчика в Discord (Настройки →
  Расширенные), ПКМ по серверу → «Копировать ID», и передай это число.
- Ошибка `401` — неверный токен. `403` — бот ниже создаваемых ролей или
  нет `Manage Roles` (вернись к шагам 2–3).
- Если `403` повторяется даже когда «Управление ролями» включено: загляни
  в **Настройки сервера → Безопасность** и проверь «Требовать двухэтапную
  аутентификацию для модерации». Если включено — у аккаунта-владельца бота
  должна быть включена 2FA (Настройки пользователя → «Моя учётная запись»),
  иначе Discord блокирует любые действия с ролями (ошибка `60003`).
  Самый быстрый проверочный вариант — временно дать роли бота
  «Администратор»: если ошибка исчезнет, дело было в правах; если нет —
  точно в 2FA.
- Порядок ролей — не косметика: роль может выдавать только роли ниже себя,
  поэтому раскладка из `--order` (персонал вверху, «Новичок» внизу) —
  правильная. Повторный запуск ничего не портит.

## Шаг 5. Выдать права персоналу

Все роли создаются **без прав** — это защита от случайностей.
**Быстрый путь** — одна команда (делает всё из таблицы ниже и заодно
переименовывает каналы «Администрации»):

```powershell
python setup_staff.py --guild-name "Перекуп Калькулятор" --apply
```

Если хочешь вручную — включи нужное в **Настройки сервера → Роли**:

| Роль | Что включить |
| --- | --- |
| `👑 Владелец` | `Администратор` (и выдать её себе) |
| `🛡️ Модератор` | `Кикать участников`, `Банить`, `Тайм-ауты`, `Управлять сообщениями`, `Управлять никами` |
| `🤖 Бот` | ничего — её выдают только ботам, чтобы отделить их от людей |
| остальные | ничего — это пинг-роли, метки и награды |

## Шаг 6. Категория «Администрация»

Если запускал `setup_staff.py` — тут уже всё готово (осталось проверить
глазами). Вручную: **Настройки сервера → Каналы → Администрация → Права**:

1. `@everyone` → выключить **Просмотр канала**.
2. Добавить `👑 Владелец` и `🛡️ Модератор` → включить **Просмотр канала**.
3. Каналы называются `#админ-чат` и `🔊 админ-войс` (скрипт из шага 5
   переименовал их сам).

## Шаг 7. Закрыть Community и создать #роли

Одна команда делает всю «финальную уборку»:

```powershell
python finish_setup.py --guild-name "Перекуп Калькулятор"            # предпросмотр
python finish_setup.py --guild-name "Перекуп Калькулятор" --apply    # применить
```

Что произойдёт:

- у категории `Community` выключится **Просмотр канала** для `@everyone`
  и включится для `✅ Знает правила`, `👑 Владелец`, `🛡️ Модератор`;
- включится средний уровень проверки (аккаунт старше 5 минут) и фильтр
  откровенного контента;
- в «Основных каналах» появится `#роли` — read-only: писать может бот,
  `👑 Владелец` и `🛡️ Модератор`;
- в `#новости`, `#медиа-новости`, `#обновления`, `#установка` и `#правила`
  писать может только персонал, `@everyone` — только читать;
- у основных каналов появятся описания (если их ещё не было).

Новичок видит `#правила` и кнопку верификации, но не видит Community,
пока не нажмёт кнопку. Это защита от raid-ботов и «залётных» аккаунтов.

## Шаг 8. Инвайт-ссылки Telegram / EXE / сайт

```powershell
python create_invites.py --guild-name "Перекуп Калькулятор"            # предпросмотр
python create_invites.py --guild-name "Перекуп Калькулятор" --apply    # создать
```

Скрипт создаст четыре бессрочные ссылки в `#welcom` и сохранит
`PerekupDisBot/invites.json`:

| Ссылка | Роль при входе | Куда вставить |
| --- | --- | --- |
| Telegram | `📱 Из Telegram` | кнопка в Telegram-боте / Mini App |
| EXE | `🖥️ Из EXE` | ссылка в EXE-приложении |
| Сайт | `🌐 С сайта` | кнопка на сайте |
| Обычная | без роли | запасная ссылка |

Повторный запуск безопасен: существующие рабочие ссылки переиспользуются,
создаются только недостающие.

## Шаг 9. Запустить Discord-бота

Бот живёт в отдельной папке `PerekupDisBot` (рядом с `DiscordCatalog`).

1. В <https://discord.com/developers/applications> → **Bot** включи
   **SERVER MEMBERS INTENT** (без него не работают приветствие и источники
   входа).
2. В папке `PerekupDisBot`:

```powershell
cd H:\Repozit\PerekupDisBot
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env          # вставь DISCORD_BOT_TOKEN
python bot.py
```

3. На сервере выполни (от аккаунта с правом «Управление сервером»):

```
/panel          → панель подписок в #роли
/verify-panel   → кнопка верификации в #правила
/status         → проверка состояния
```

Если Server Members Intent пока не включён, панели можно поставить
командой `python bot.py --publish` — бот опубликует их и выйдет. Но
приветствие и источник входа заработают только после включения интента.

Подробности, деплой на Railway/Render/VPS и разбор ошибок — в
`PerekupDisBot/README.md`.

## Шаг 10. Вебхук обновлений

```powershell
python post_update.py --guild-name "Перекуп Калькулятор" --create-webhook --apply
python post_update.py --test --apply
```

Скрипт создаст вебхук `Perekup Updates` в `#обновления`, сохранит URL в
`DiscordCatalog/.env` как `DISCORD_WEBHOOK` и отправит тестовый пост
(сразу удалит его). URL в чат не печатается.

Анонс релиза вручную:

```powershell
python post_update.py --title "Версия 1.4" --version 1.4 `
  --url "https://github.com/proctogad/perekup-webapp/releases" `
  --notes "Что нового: ..." --apply
```

Автоматические анонсы GitHub Releases — пример workflow в
`examples/github-release-webhook.yml`: скопируй его в
`.github/workflows/discord-release.yml` и добавь секрет `DISCORD_WEBHOOK`
в настройках репозитория.

## Шаг 11. Оформление и защита

- **Иконка и баннер** — Настройки сервера → «Обзор» → загрузить иконку
  и баннер. Иконка видна в списке серверов и в инвайтах.
- **2FA для модерации** — Настройки сервера → «Безопасность» → включить
  «Требовать двухэтапную аутентификацию для модерации». Тогда угнанный
  аккаунт модератора не сможет банить.
- **Правила** — готовый текст в `rules-text.md`: скопируй в `#правила`,
  закрепи, после этого опубликуй кнопку через `/verify-panel`.
- **Community-онбординг** (по желанию) — Настройки сервера → «Community»:
  включить, выбрать `#правила` каналом правил и `#обновления` каналом
  обновлений, заполнить приветственный экран. Это даст экран «Заходи»,
  но не обязательно для работы бота.
- **Резервная копия** — Настройки сервера → «Шаблон сервера» → создать
  шаблон. Роли и каналы можно будет восстановить, если что-то сломается.

## Частые вопросы

| Вопрос | Ответ |
| --- | --- |
| Поменять цвет или имя роли | правь `roles.plan.json` и запусти `--apply --update` (или мышкой в Discord) |
| Удалить роль | мышкой в Discord; план ничего не удаляет сам |
| Что такое `📱 Из Telegram` и т.д. | метки «откуда пришёл»; их выдаёт бот по инвайт-ссылкам (шаг 8) |
| Странные имена `#1` и `🔊1` | похоже, ты создавал их на скорую руку — переименуй (шаг 6) |
| Эмодзи в роли не как у канала | поправь имя в `roles.plan.json` → `--apply --update` |
| Бот не запускается: `PrivilegedIntentsRequired` | включи **SERVER MEMBERS INTENT** в портале (шаг 9) |
| Кнопки не реагируют | бот не запущен или упал; смотри логи, после правки `config.json` выполни `/panel` заново |
| Панель пропала после переезда | выполни `/panel` ещё раз — бот найдёт старое сообщение или опубликует новое |
| Хочу новые инвайт-ссылки | удали `PerekupDisBot/invites.json` и запусти `create_invites.py --apply` заново; старые ссылки останутся рабочими, пока их не отозвать вручную |
