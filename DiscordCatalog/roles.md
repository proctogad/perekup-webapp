# Роли сервера — GTA5RP | Перекуп Калькулятор

Полный набор: **29 ролей** — по одной на каждый канал (17), источник входа
(3), персонал (3) и особые/заслуги (6). Машинный план — `roles.plan.json`,
создать всё на сервере — `create_roles.py --apply`, пошаговая инструкция —
в `SETUP.md`.

## Логика системы

| Тип | Как работает |
| --- | --- |
| Пинг-подписки | `@роль` в посте — уведомление только подписанным. Подписка — кнопками в `#роли` (Discord-бот) или вручную. |
| Источник входа | Метка «откуда пришёл»: своя инвайт-ссылка на Telegram, EXE и сайт; бот смотрит, какую ссылку использовали, и вешает роль. |
| Персонал | Владелец и модераторы. Создаются без прав — выдайте их сами (см. ниже), плюс они открывают категорию «Администрация». |
| Заслуги | Награды: бустер, первопроходец, тестер, автор отзыва, контентмейкер, топ сезона. |
| Голосовые | Пинг на сбор в конкретной комнате: гонки, стрим, скупка. |

Все роли создаются с нулевыми правами и не меняют доступ к каналам — это
безопасно. Доступы настраиваются отдельно (например, «Администрация» —
только для владельца и модераторов, Community — для `✅ Знает правила`).

## Порядок в иерархии

Выше в списке — главнее. Порядок групп в `roles.plan.json` — это и есть
порядок иерархии, а команда ниже раскладывает все роли автоматически
(и сама поднимает роль бота, если она оказалась внизу списка):

```powershell
python create_roles.py --guild-name "Перекуп Калькулятор" --apply --order
```

- хочется по-классике, чтобы сверху красовался `👑 Владелец` — перетащи
  `Perekup` на 3-е место: ничего не сломается, но бот перестанет сам
  трогать роли `Владелец` и `Модератор` (а ему это и не нужно).

## Самоназначение пинг-ролей

У 14 ролей в `roles.plan.json` стоит `"self_assign": true` — их можно
выдавать кнопками в панели подписок:

`📰 Новости`, `📺 Медиа-новости`, `🔔 Обновления`, `📲 Уставка`,
`📅 Мероприятия`, `⭐ Отзывы`, `💡 Идеи`, `☕ Чат`, `🏷️ Скины и мемы`,
`📎 Баг-хантер`, `🔊 Войс-1 · Лобби`, `🎧 Войс-2 · Гонки`,
`🎤 Войс-3 · Стрим`, `📢 Войс-4 · Скупка`.

Панель публикует Discord-бот в канале `#роли` (команда `/panel`).
Кнопка работает как переключатель: нажал — роль появилась, нажал ещё раз —
снялась. Это только пинги: доступ к каналам такие роли не меняют.
`🧠 Хелпер` и служебные роли кнопками не выдаются — их назначает персонал.

## Как применить

```powershell
# посмотреть план без токена (уже в порядке иерархии)
python create_roles.py --list

# предпросмотр: что будет создано (роли с таким же именем уже не дублируются)
$env:DISCORD_BOT_TOKEN = "твой-токен"
python create_roles.py --guild-name "Перекуп Калькулятор"

# создать роли
python create_roles.py --guild-name "Перекуп Калькулятор" --apply

# разложить роли по порядку иерархии (сверху вниз, как в списке выше)
python create_roles.py --guild-name "Перекуп Калькулятор" --apply --order

# подтянуть цвета/пинг у уже созданных ролей
python create_roles.py --guild-name "Перекуп Калькулятор" --apply --update

# выдать права персоналу, открыть «Администрацию», переименовать админ-каналы
python setup_staff.py --guild-name "Перекуп Калькулятор" --apply

# закрыть Community, создать #роли, заполнить описания
python finish_setup.py --guild-name "Перекуп Калькулятор" --apply

# создать инвайты Telegram / EXE / сайт
python create_invites.py --guild-name "Перекуп Калькулятор" --apply
```

Требования к боту: право **Manage Roles**, и его высшая роль должна быть
выше создаваемых; с флагом `--order` скрипт поднимает роль бота сам, а если
Discord не разрешит — попросит перетащить её мышкой. Подробнее — `SETUP.md`.

## Правки

- Переименовать/добавить/убрать роль: правьте `roles.plan.json` — создаются
  и обновляются только роли из плана, лишние не трогаются.
- Существующие роли ищутся по имени (регистр не важен): одноимённую роль
  скрипт не продублирует.
- Порядок ролей задаётся планом: порядок групп в файле = иерархия сверху
  вниз. Поменяли порядок в плане — перезапустите с `--apply --order`.
